Ключевые решения

1
Тег crypto не работает
Gamma на tag=crypto отдаёт политику. Поэтому discovery через slug: первый сегмент = актив (btc-up-or-down-5m → btc), паттерн = тип рынка.
2
closed=false не отсекает прошлое
Recurring-серии pre-deploy'ят на сутки вперёд, старые не помечают closed. Фильтрую сам: endDate ≥ now, пагинация останавливается на первом прошедшем.
3
Двойная JSON-кодировка
outcomes и clobTokenIds приходят строками "[\"Up\",\"Down\"]" → распаковываю json.loads().
4
Цена Up = бид на Yes
Для свечи [Up, Down]: вероятность Up = bestBid, Down = 1 − Up, mid = (bid+ask)/2. Всё из Gamma, CLOB /midpoint — запасной.
5
Сквозные ключи
conditionId (рынок) и token_yes (токен) связывают рынок → стакан → сделки → кошельки.
6
TTL-кэш 5 секунд
Стакан и сделки кэшируются 5с, чтобы не долбить API при каждом клике.

Собираемые типы и поля

  • Типы рынков (4): up-or-down (свечи), hit-price, multi-strikes, neg-risk
  • Активы (8): btc, eth, sol, xrp, doge, bnb, link, ena
  • Таймфреймы (7): 5m, 15m, 4h, hourly, daily, weekly, monthly
  • Рынок: question, asset, recurrence, endDate, outcomes, bid/ask/mid, spread, conditionId, token_yes/no, volume, liquidity
  • Стакан: bids[], asks[] (цена+размер), last_trade_price, tick_size
  • Сделки: side, outcome, price, size, timestamp, wallet (proxyWallet), pseudonym, txHash
  • Кошельки: wallet, pseudonym, buys/sells, buy_usd/sell_usd, net_shares
